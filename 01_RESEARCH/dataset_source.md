# DATASET SOURCES

## 1. Introduction

This project, titled **Road Traffic Accident Analysis**, uses secondary data collected from reliable and publicly accessible sources. The data is intended to support the analysis of road traffic accidents, vehicle involvement, casualties, accident severity, and road safety patterns.

The research initially focuses on Rwanda, Kenya, Uganda, and other countries where suitable data is available.

## 2. Primary Dataset Source

**Organization:** UK Department for Transport

**Dataset:** Road Safety Open Data

**Official URL:** https://www.gov.uk/government/statistical-data-sets/road-safety-open-data

**Geographical Coverage:** Great Britain (England, Scotland, and Wales).

**Dataset format:** CSV

**Data categories:**
- Road traffic collisions
- Vehicles involved in collisions
- Casualties resulting from collisions

**Reporting period:** 2025 dataset, subject to verification of the downloaded files.

## 3. Dataset Description

### 3.1 Collisions Dataset

This dataset contains information about reported road traffic collisions, including accident dates, locations, road conditions, weather conditions, and accident severity where available.

### 3.2 Vehicles Dataset

This dataset contains information about vehicles involved in reported collisions, including vehicle types and other vehicle-related characteristics.

### 3.3 Casualties Dataset

This dataset contains information about people injured or killed in reported road traffic collisions, including casualty characteristics and injury severity.

## 4. Additional African Data Sources

The research will investigate the availability of road traffic accident datasets from the following countries:

- Rwanda: https://data.gov.rw/
- Kenya: https://www.knbs.or.ke/
- Uganda: https://www.ubos.org/
- World Health Organization: https://www.who.int/

The availability of individual accident, vehicle, and casualty records from these sources must be verified before including them in the database.

## 5. Data Collection Method

The data collection process involves:

1. Identifying official and reliable data sources.
2. Downloading publicly available datasets.
3. Recording the original source URLs.
4. Identifying the geographical coverage and reporting period.
5. Inspecting dataset structures and column names.
6. Recording dataset formats and licensing conditions.
7. Preserving original downloaded datasets.

## 6. Data Usage

The collected datasets will be used for academic research, database design, Oracle Database implementation, and road traffic accident analysis.

## 7. Source Verification

The actual downloaded files, reporting periods, record counts, column names, and licensing conditions will be verified and documented before database implementation.

## 8. Conclusion

Reliable data sources are essential for producing meaningful road traffic accident analysis. The project will prioritize official sources and clearly document the origin and geographical coverage of every dataset used.
