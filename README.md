# ROAD TRAFFIC ACCIDENT ANALYSIS

**An Academic Project at AUCA**

## 1. Project Overview

This project focuses on collecting, storing, managing and analyzing road traffic accident data using **Oracle Database, SQL and Power BI**.

The project aims to understand road accidents, identify common causes, examine accident severity and casualties, and identify areas with high accident levels.

The main countries of interest are Rwanda, Kenya and Uganda. Other countries may be included when reliable data is available.

## 2. Project Objectives

- Collect road traffic accident data.
- Clean and organize the collected data.
- Design and implement a database using Oracle.
- Analyze accident frequency and severity using SQL.
- Identify common accident causes and affected road users.
- Create interactive dashboards using Power BI.
- Provide recommendations for improving road safety.

## 3. Data Sources

The project uses information from the following sources:

| Source | Country / Coverage | Data |
|---|---|---|
| Rwanda National Institute of Statistics (NISR) | Rwanda | Road accident statistics |
| Rwanda National Police | Rwanda | Road accident records and reports |
| Kenya National Police Service | Kenya | Road accident statistics |
| Uganda Police Force | Uganda | Road accident statistics |
| World Health Organization (WHO) | International | Road safety indicators |
| UK Department for Transport (STATS19) | Great Britain | Collision, vehicle and casualty records |

### Official Data Links

1. Rwanda: https://www.statistics.gov.rw/
2. Kenya: https://nationalpolice.go.ke/
3. Uganda: https://upf.go.ug/
4. WHO: https://www.who.int/teams/social-determinants-of-health/safety-and-mobility
5. Great Britain STATS19: https://www.gov.uk/government/statistical-data-sets/road-safety-open-data

**Note:** Each dataset will be analyzed according to its country, reporting period and available information. STATS19 represents Great Britain, not Rwanda, Kenya or Uganda. Country-level statistics will not be treated as individual accident records.
